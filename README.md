# حصن المسلم | Hisn Al Muslim

A modern Islamic web platform built with Next.js, TypeScript, and Tailwind CSS that provides Muslims with essential daily tools in a clean, responsive, and user-friendly experience.

---

## ✨ Features

### 📖 Quran

- Browse all 114 Surahs
- Read complete Surahs
- Continue Reading feature
- Popular Surahs section
- Customizable reading settings

### 🤲 Daily Azkar

- Morning Azkar
- Evening Azkar
- After Prayer Azkar

### 🕌 Prayer Times

- Accurate prayer times based on user location
- Next prayer countdown
- Prayer calendar for custom date ranges
- Hijri date support

### 🧭 Qibla Direction

- Real-time Qibla compass
- Automatic geolocation support

### 📚 Hadith Search Engine

- Search Hadith collections
- Filter by book and status
- Pagination support
- Detailed Hadith pages

### ✨ Asma Al-Husna

- Browse the 99 Names of Allah
- Search functionality
- Meanings and descriptions

### 📅 Islamic Calendar

- Islamic special days
- Hijri ↔ Gregorian date converter

### 🌙 User Experience

- Responsive Design
- Fast Performance
- Loading States
- Error Boundaries
- SEO Optimized

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/hisn-al-muslim.git

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
